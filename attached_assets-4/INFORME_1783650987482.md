## 3. `remix_-remix_-editor-de-brochure-clientum/` — Editor de Brochure con IA

App independiente construida con **Google AI Studio** (Gemini API). Permite crear brochures comerciales personalizados de Clientum para prospectos.

### Stack
- React + Vite + TypeScript
- Gemini API (requiere `GEMINI_API_KEY`)
- jsPDF (exportación a PDF)
- Tailwind CSS

### Vistas principales (`viewMode`)

| Vista | Descripción |
|-------|-------------|
| `editor` | Editor de brochure con sidebar y preview en tiempo real |
| `website` | Sitio público simulado del cliente |
| `prospector` | Dashboard de prospección con IA |

### Componentes

| Componente | Función |
|-----------|---------|
| `SidebarEditor.tsx` | Panel de edición: textos, presets de industria, temas de color, plantillas |
| `BrochurePreview.tsx` | Vista previa del brochure (8 páginas, exportable a PDF) |
| `PublicWebsite.tsx` | Simulación del sitio web público del prospecto |
| `SalesAssistantChat.tsx` | Chat IA de asistente de ventas (Gemini) |
| `SalesProspectorDashboard.tsx` | Dashboard CRM de prospectos con scoring MEDDIC |
| `ChatbotSim.tsx` | Simulación del chatbot de WhatsApp |
| `InteractiveAIChat.tsx` | Chat IA con soporte de gráficos |
| `InteractiveCRMKanban.tsx` | Kanban CRM interactivo |
| `SidebarCRM.tsx` | Panel lateral del módulo CRM |

### Modelo de datos (`BrochureData`)

```typescript
BrochureData {
  cover: { slogan, sub }
  chatbot: { title, features[], flowSteps[] }
  crm: { title, features[], stageLabels, deals[] }
  services: ServiceItem[]  // con precio, tiempo estimado
  testimonial: { text, author, company }
  outreachEmail?: string
  images?: Record<number, string>
  logoUrl?: string
}
```

### Modelo MEDDIC por deal (`CRMDeal`)

Cada prospecto en el pipeline tiene scoring MEDDIC completo:
- `meddicMetrics` · `meddicBuyer` · `meddicCriteria` · `meddicProcess` · `meddicPain` · `meddicChampion`
- `meddicScore` · `meddicRedFlags` · `meddicNextActions[]`

### Secuencias de outreach por deal
- `outreachEmail1/2/3` — 3 emails en secuencia
- `outreachLinkedIn[]` — mensajes para LinkedIn
- `outreachPhoneScript` — guión telefónico

### Presets de industria
Incluye preset `gaman` (y posiblemente otros) con datos preconfigurados para distintas industrias objetivo.

### Servicios (`src/services/scraperService.ts`)
Servicio para scraping de datos de prospectos (posiblemente integrado con guiacores.com).

### Exportación (`src/utils/pdfGenerator.ts`)
Generación de PDF del brochure de 8 páginas con `jsPDF`.

### Assets de imágenes
3 variantes de logo de Clientum en JPG:
- `clientum_logo_one_*.jpg`
- `clientum_logo_two_*.jpg`
- `clientum_logo_three_*.jpg`
